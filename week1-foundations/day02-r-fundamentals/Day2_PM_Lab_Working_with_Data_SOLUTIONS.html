2 Exercise 1

Cholesterol by diabetes status.

framingham |>
  group_by(diabetes) |>
  summarize(
    n        = n(),
    mean_chol = mean(totChol, na.rm = TRUE),
    sd_chol   = sd(totChol,   na.rm = TRUE),
    med_chol  = median(totChol, na.rm = TRUE),
    .groups  = "drop"
  )
# A tibble: 2 × 5
  diabetes     n mean_chol sd_chol med_chol
  <fct>    <int>     <dbl>   <dbl>    <dbl>
1 No        4131      236.    44.2     234.
2 Yes        109      248.    57.3     240

Diabetic and non-diabetic participants have similar mean total cholesterol (roughly 236 vs. 248 mg/dL), with the diabetic group showing a slightly higher mean. The difference is small and does not suggest a strong univariate association between diabetes status and cholesterol in this sample.

3 Exercise 2

Pulse pressure and BMI category.

framingham <- framingham |>
  mutate(
    pulse_pressure = sysBP - diaBP,
    bmi_category   = case_when(
      BMI < 18.5              ~ "Underweight",
      BMI >= 18.5 & BMI < 25 ~ "Normal",
      BMI >= 25   & BMI < 30 ~ "Overweight",
      BMI >= 30               ~ "Obese",
      .default = NA_character_
    )
  )

framingham |>
  group_by(bmi_category) |>
  summarize(
    n                  = n(),
    mean_pulse_pressure = mean(pulse_pressure, na.rm = TRUE)
  )
# A tibble: 5 × 3
  bmi_category     n mean_pulse_pressure
  <chr>        <int>               <dbl>
1 Normal        1870                47.3
2 Obese          539                53.8
3 Overweight    1755                50.6
4 Underweight     57                43.3
5 <NA>            19                55.7

Mean pulse pressure increases monotonically with BMI category, rising from about 47 mmHg in the Normal group to about 54 mmHg in the Obese group. This is consistent with higher arterial stiffness in individuals with greater body mass.

4 Exercise 3

Female non-smokers over age 55: base R vs. dplyr.

# Base R version
subset_baseR <- framingham[
  framingham$male == "Female" &
  framingham$currentSmoker == "Non-smoker" &
  framingham$age > 55,
]
nrow(subset_baseR)
[1] 505
mean(subset_baseR$glucose, na.rm = TRUE)
[1] 86.71552
# dplyr version
subset_dplyr <- framingham |>
  filter(
    male          == "Female",
    currentSmoker == "Non-smoker",
    age           > 55
  )
nrow(subset_dplyr)
[1] 505
mean(subset_dplyr$glucose, na.rm = TRUE)
[1] 86.71552

Both approaches return the same row count. Mean glucose in this subgroup is approximately 87 mg/dL, which is within the normal fasting range. The dplyr version is easier to read and extend; the base R version is useful to know for contexts where tidyverse is unavailable.

5 Exercise 4

Cigarette use among current smokers; heavy smoker flag.

# Summary among current smokers
framingham |>
  filter(currentSmoker == "Smoker") |>
  summarize(
    n            = n(),
    mean_cpd     = mean(cigsPerDay, na.rm = TRUE),
    sd_cpd       = sd(cigsPerDay,   na.rm = TRUE),
    min_cpd      = min(cigsPerDay,  na.rm = TRUE),
    max_cpd      = max(cigsPerDay,  na.rm = TRUE),
    .groups      = "drop"
  )
# A tibble: 1 × 5
      n mean_cpd sd_cpd min_cpd max_cpd
  <int>    <dbl>  <dbl>   <dbl>   <dbl>
1  2095     18.4   10.9       1      70
# Add heavy_smoker to full dataset and count
framingham |>
  mutate(heavy_smoker = cigsPerDay > 20) |> 
  summarise(
    pct_heavy_smk = mean(heavy_smoker, na.rm = TRUE) * 100,
    num_heavy_smk = sum(heavy_smoker, na.rm = TRUE)
         )
# A tibble: 1 × 2
  pct_heavy_smk num_heavy_smk
          <dbl>         <int>
1          10.9           460

Among current smokers, the average is roughly 18 cigarettes per day (close to a pack), with a wide range. About 11% of people are classified as heavy smokers. Note that cigsPerDay contains some missingness, so na.rm = TRUE is essential throughout.

6 Exercise 5

10-year CHD rate by education level.

framingham |>
  group_by(education) |>
  summarize(
    n        = n(),
    chd_pct  = mean(TenYearCHD == "Yes", na.rm = TRUE) * 100
  ) |>
  filter(!is.na(education)) |> # Remove the education = NA group.
  arrange(desc(chd_pct))
# A tibble: 4 × 3
  education          n chd_pct
  <fct>          <int>   <dbl>
1 Some HS         1720    18.8
2 College Degree   473    14.8
3 Some College     689    12.8
4 HS Diploma      1253    11.7

CHD rates are highest among participants with the lowest education (Some HS), and the lowest 10-year CHD risk is among those with a HS Diploma.

7 Exercise 6 (Challenge)

Multi-step pipeline: ages 40–65, hypertension-smoker interaction, CHD rates by subgroup.

framingham |>
  filter(age >= 40, age <= 65) |>
  mutate(
    hyp_smoker = if_else(
      prevalentHyp == "Yes" & currentSmoker == "Smoker",
      "Yes", "No"
    )
  ) |>
  group_by(hyp_smoker, male) |>
  summarize(
    n         = n(),
    mean_sysBP = mean(sysBP,  na.rm = TRUE),
    chd_pct   = mean(TenYearCHD == "Yes", na.rm = TRUE) * 100,
    .groups   = "drop"
  ) |>
  filter(n >= 50) |>
  arrange(desc(chd_pct))
# A tibble: 4 × 5
  hyp_smoker male       n mean_sysBP chd_pct
  <chr>      <fct>  <int>      <dbl>   <dbl>
1 Yes        Male     290       151.    31.4
2 Yes        Female   201       158.    18.4
3 No         Male    1231       128.    17.5
4 No         Female  1852       132.    12.7

Among adults aged 40–65, males with both prevalent hypertension and current smoking (hyp_smoker == "Yes", male == "Male") show the highest 10-year CHD rate (31.4%). The combination of hypertension and smoking acts synergistically: each risk factor alone elevates risk, but their co-occurrence is associated with substantially higher rates than either alone.

There are no groups with fewer than 50 participants, so the final filtering does not have any effect.
