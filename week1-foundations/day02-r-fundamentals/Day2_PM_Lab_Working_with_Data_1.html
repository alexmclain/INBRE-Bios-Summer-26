1 Overview

This lab draws on everything covered so far:

  • Day 1: R basics, object types, indexing with $ and [ ], mathematical functions, reading data, inspecting with str() / summary() / head()
  • Day 2 AM: Variable types, factors, strings, dplyr verbs (filter(), mutate(), select(), arrange(), group_by(), summarize()), and pipes

The dataset is the Framingham Heart Study, a landmark longitudinal study of cardiovascular disease risk factors. The file framingham.csv is in the data/ folder. It contains 4,240 participants and 16 variables.

How this lab works:

  • Part 1 (instructor demo, ~25 min): Follow along as the instructor works through the setup, data inspection, and variable type correction. Run the code on your own machine as you go.
  • Part 2 (on your own, ~90 min): Complete the exercises independently. The quick reference card at the bottom of this document has the key functions you need. The instructor is in the room for questions.

2.3 Fixing Variable Types

Several variables are stored as numbers but represent categories. Left as-is, a regression model will treat them as continuous — almost always wrong.

Variable Coding
male 0 = Female, 1 = Male
currentSmoker 0 = Non-smoker, 1 = Smoker
BPMeds 0 = No, 1 = Yes
prevalentStroke 0 = No, 1 = Yes
prevalentHyp 0 = No, 1 = Yes
diabetes 0 = No, 1 = Yes
TenYearCHD 0 = No event, 1 = CHD within 10 years
education 1 = Some HS, 2 = HS Diploma, 3 = Some College, 4 = College Degree 
framingham <- framingham |>
  mutate(
    male            = factor(male,            levels = c(0, 1),
                                              labels = c("Female", "Male")),
    currentSmoker   = factor(currentSmoker,   levels = c(0, 1),
                                              labels = c("Non-smoker", "Smoker")),
    BPMeds          = factor(BPMeds,          levels = c(0, 1),
                                              labels = c("No", "Yes")),
    prevalentStroke = factor(prevalentStroke, levels = c(0, 1),
                                              labels = c("No", "Yes")),
    prevalentHyp    = factor(prevalentHyp,    levels = c(0, 1),
                                              labels = c("No", "Yes")),
    diabetes        = factor(diabetes,        levels = c(0, 1),
                                              labels = c("No", "Yes")),
    TenYearCHD      = factor(TenYearCHD,      levels = c(0, 1),
                                              labels = c("No", "Yes")),
    education       = factor(education,       levels = 1:4,
                                              labels = c("Some HS", "HS Diploma",
                                                         "Some College",
                                                         "College Degree"))
  )

2.4 One Worked Example

Here is a complete pipeline combining what we have done. Read each step before running:

# Among participants NOT on BP medication,
# compute mean systolic BP and CHD rate by hypertension status and sex
framingham |>
  filter(BPMeds == "No") |>
  group_by(prevalentHyp, male) |>
  summarize(
    n          = n(),
    mean_sysBP = mean(sysBP, na.rm = TRUE),
    sd_sysBP = sd(sysBP, na.rm = TRUE),
    chd_pct    = mean(TenYearCHD == "Yes", na.rm = TRUE) * 100,
    .groups    = "drop"
  ) |>
  arrange(desc(chd_pct))
# A tibble: 4 × 6
  prevalentHyp male       n mean_sysBP sd_sysBP chd_pct
  <fct>        <fct>  <int>      <dbl>    <dbl>   <dbl>
1 Yes          Male     530       150.     18.6   27.2 
2 Yes          Female   641       158.     20.1   20.7 
3 No           Male    1240       123.     11.9   14.8 
4 No           Female  1652       122.     13.7    7.93
Tip

This is the template for most of the exercises below: filter() to narrow the data, mutate() to create new variables, group_by() + summarize() to compute group statistics, then arrange() to sort the result.

4.1 Reading and Inspecting Data

Function What it does
read_csv("file.csv") Read a CSV file; returns a tibble
dim(df) Number of rows and columns
names(df) Column names
str(df) Structure: type and example values of every column
summary(df) Summary statistics; shows NA counts
head(df, n) First n rows (default 6)
View(df) Open spreadsheet viewer in RStudio
colSums(is.na(df)) Count of missing values per column

4.2 Indexing (Base R)

Syntax What it does
df$col Extract column as a vector
df[i, ] Row i, all columns
df[, j] All rows, column j
df[condition, ] Rows where condition is TRUE
df[["col"]] Extract column by name (useful when name is in a variable)

4.3 Variable Types

Function What it does
factor(x, levels, labels) Convert to factor with named levels
levels(f) Show the levels of a factor
class(x) Check the type of an object
is.na(x) Logical vector: TRUE where values are missing

4.4 dplyr Verbs

Function What it does
filter(df, condition) Keep rows where condition is TRUE
select(df, col1, col2) Keep specified columns
mutate(df, new = expr) Add or modify columns
arrange(df, col) Sort rows; desc(col) for descending
group_by(df, col) Group rows for subsequent summaries
summarize(df, stat = expr) Collapse groups to summary rows
n() Count rows (use inside summarize())

4.5 Useful Expressions Inside mutate / summarize

Expression What it does
mean(x, na.rm = TRUE) Mean, ignoring NAs
sd(x, na.rm = TRUE) Standard deviation
median(x, na.rm = TRUE) Median
sum(x, na.rm = TRUE) Sum
min(x, na.rm = TRUE) / max(x, na.rm = TRUE) Min / max
sum(is.na(x)) Count missing values
mean(var == "Yes") Proportion where condition is TRUE
case_when(cond1 ~ val1, cond2 ~ val2, TRUE ~ val3) Recode with multiple conditions
if_else(condition, true_val, false_val) Simple two-way recode
